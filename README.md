# FRONTRUN

A fully on-chain, long-form generative art collection. Animated. On Ethereum.

**[▶ Open the preview](https://strangersolemn.github.io/frontrun/)**

Paste any wallet — or an ENS name — to see the piece it generates, or hit **roll**.
Every wallet maps to its own piece, the same one every time.

No libraries. Raw browser JS. The art doesn't exist until it's rendered in a window.

— strangersolemn
